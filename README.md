# Дом Шинобу

Личный архив для одного человека: арты по датам, рукописный каталог к ним, дневник,
рассказы, голосовые заметки и гардероб — в одном доме, где всё можно листать и искать.

Сервис **только читает** папку с данными. Он никогда ничего в ней не создаёт, не
переносит и не удаляет: база данных и миниатюры живут отдельно (`DOM_DB_PATH`,
`DOM_CACHE_DIR`), а если указать их внутри папки данных, сервис откажется запускаться.
Никаких внешних запросов во время работы: ни CDN, ни шрифтов из интернета, ни JavaScript.

## Что умеет

- **Библиотека** (`/`) — сетка артов с миниатюрами, фильтры по датам, папке, наличию
  описания в каталоге и модели, полнотекстовый поиск по названиям, каталогу и дневнику
  (SQLite FTS5, русские слова ищутся целиком и по началу слова), постраничный вывод.
- **Страница арта** (`/art/<id>`) — картинка в полном размере, таблица метаданных,
  описание из каталога, промпт из файла, другие арты той же сессии, «назад/вперёд».
- **Хроника** (`/timeline`) — лента по дням от новых к старым: записи дневника, арты и
  рассказы; у каждого дня есть якорь `#d-ГГГГ-ММ-ДД`.
- **Дневник** (`/diary`), **рассказы** (`/stories`), **гардероб** (`/wardrobe`) —
  удобное чтение, у каждого раздела свой якорь.
- **Голоса** (`/audio`) — список записей со встроенным плеером, перемотка работает
  (HTTP Range).
- **Кладовая** (`/pick`) — вытягивает N случайных артов. Арт, выпавший за последние
  `DOM_PICK_COOLDOWN_DAYS` дней, не повторяется; только если на «отдыхе» все арты сразу,
  выбор идёт из всей коллекции. Если свободных артов меньше, чем просили, выпадет столько,
  сколько свободно. История хранится в базе.
- **Статистика** (`/stats`) — цифры, кнопка переиндексации и отчёт последней индексации:
  ненайденные папки, файлы, которые не удалось разобрать, расхождения контрольных сумм,
  записи каталога без файла.

## Как устроена папка данных

```
~/Shinobu/
├── arts/                      арты: подпапки ГГГГ-ММ-ДД и файлы прямо в корне
├── арты/
│   ├── 2025-03-14/…           .png .jpg .jpeg .webp .gif
│   ├── каталог.md             описания артов
│   └── контрольные-суммы.txt  строки «sha256  путь»
├── дневник.md                 разделы «## ГГГГ-ММ-ДД — заголовок»
├── рассказы/*.md
├── голосовые/                 .ogg .mp3 .wav .flac
├── звуки/
└── гардероб.md
```

Любой части может не быть — сервис просто отметит это в отчёте. Формат записи каталога:

```markdown
## 2025-03-14 — Кошка на крыше
`one.png` · PNG 1024x1024 · 1.2 MB · flux-dev, seed 12345

Рыжая кошка сидит на черепичной крыше под луной.
```

Запись связывается с файлом по имени (при совпадении имён предпочитается файл с той же
датой). Дата арта берётся из имени папки, затем из имени файла, иначе — из даты изменения.
Если в PNG есть текстовые блоки (A1111 `parameters`, ComfyUI `prompt`/`workflow`) или в
JPEG — EXIF-комментарий, оттуда извлекаются промпт, seed и модель.

## Установка

Нужен Python 3.12 (SQLite с FTS5 входит в стандартную сборку).

```bash
git clone <репозиторий> /opt/dom && cd /opt/dom
python3.12 -m venv .venv
.venv/bin/pip install .
```

## Настройка

Только через переменные окружения:

| Переменная | По умолчанию | Что это |
|---|---|---|
| `DOM_DATA_DIR` | `~/Shinobu` | папка с данными (только чтение) |
| `DOM_DB_PATH` | `./dom.sqlite3` | файл базы SQLite |
| `DOM_CACHE_DIR` | `./dom-cache` | миниатюры (webp, до 480 px) |
| `DOM_PORT` | `8000` | порт веб-сервера |
| `DOM_HOST` | `127.0.0.1` | адрес, на котором слушать |
| `DOM_PICK_COOLDOWN_DAYS` | `5` | сколько дней арт «отдыхает» после кладовой |

## Запуск

```bash
export DOM_DATA_DIR=~/Shinobu
.venv/bin/python -m dom ingest            # проиндексировать (повторно — быстро, только изменения)
.venv/bin/python -m dom serve             # открыть http://127.0.0.1:8000
.venv/bin/python -m dom pick --count 3    # вытянуть три арта из кладовой
.venv/bin/python -m dom stats             # статистика
```

У `ingest`, `pick` и `stats` есть флаг `--json`. Первая индексация считает sha256 и
делает миниатюры для всех файлов, поэтому на тысячах артов может занять несколько минут;
следующие пропускают файлы, у которых не изменились размер и время изменения.

JSON-эндпоинты: `POST /api/ingest`, `POST /api/pick?count=N`, `GET /api/stats`.

## Запуск как служба systemd

```bash
sudo useradd --system --home /opt/dom shinobu   # или используйте своего пользователя
sudo cp deploy/dom.service /etc/systemd/system/dom.service
sudoedit /etc/systemd/system/dom.service        # поправьте User, DOM_DATA_DIR, ReadOnlyPaths
sudo systemctl daemon-reload
sudo systemctl enable --now dom
journalctl -u dom -f
```

Служба при старте делает индексацию, а затем поднимает сервер. Папка данных
смонтирована для неё только на чтение (`ProtectHome=read-only`, `ReadOnlyPaths`), база
лежит в `/var/lib/dom`, миниатюры — в `/var/cache/dom`. Переменные можно переопределить
в `/etc/dom.env`. Чтобы переиндексировать без перезапуска — кнопка на странице
«Статистика» или `curl -X POST http://127.0.0.1:8000/api/ingest`.

Сервис рассчитан на одного владельца и не имеет входа по паролю: держите его на
`127.0.0.1` или за обратным прокси с авторизацией.

## Разработка

```bash
.venv/bin/pip install -e '.[dev]'
.venv/bin/pytest -q
.venv/bin/ruff check .
```

Тесты собирают миниатюрную папку данных во временном каталоге и работают без сети.
